## 2. Частоты: что повторяется

| Приём | Сколько сайтов | Вывод |
|---|---|---|
| Синий как primary или главный CTA | 6 из 12 | Синий — базовый язык категории |
| Тёмно-синий/почти чёрный текст | 7 из 12 | Текст не чистый чёрный, а насыщенный navy |
| Оранжевый/коралловый как акцент | 4 из 12 | Тёплый акцент — второй по частоте |
| Светло-серый фон страницы при белых карточках | 5 из 12 | Рабочая зона серая, контент белый |
| Скругления 8px | 3 из 12 (но максимум повторов внутри сайтов) | 8px — базовый радиус |
| Скругления 4–6px | 2 из 12 | Есть «плотный» вариант для таблиц |
| Inter как текстовый шрифт | 2 из 12 | Плюс system-ui у трети сайтов |
| Зелёный как цвет бренда/успеха | 3 из 12 | Успех — зелёный, отдельно от primary |

Общая картина: категория почти единодушно строится на **синем действии + тёмно-синем тексте + серо-белых поверхностях + 8px скруглениях + Inter**. Фиолетовый (usedesk, front, helpscout) и оранжевый (chat2desk, naumen, intercom, gorgias) идут как второй слой — их и берём в акцент.

Типографика:

- Текст: `Inter` → fallback `-apple-system, Segoe UI, Roboto, system-ui, sans-serif` (2 сайта прямо на Inter, треть — на system-ui).
- Код и числа в таблицах: `JetBrains Mono` → `Consolas, monospace`.
- Шкала: 12 / 13 / 14 / 16 / 18 / 20 / 24 / 30 / 36 px. База интерфейса — 14px, база текста — 16px.
- Заголовки: 600, трекинг `-0.01em`. Основной текст: 400, `line-height 1.55`. Мелкие подписи: 500, 12px, uppercase, трекинг `0.04em`.

Форма:

- Радиусы: `6px` (поля, теги), `8px` (карточки, кнопки — базовый), `12px` (панели), `16px` (модальные окна), `999px` (пилюли, аватары).
- Сетка отступов: 4px. Ряд: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64.
- Тени: `--sd-shadow-xs 0 1px 2px rgba(15,30,53,.06)`, `--sd-shadow-sm 0 2px 6px rgba(15,30,53,.07)`, `--sd-shadow-md 0 6px 18px rgba(15,30,53,.10)`, `--sd-shadow-lg 0 16px 40px rgba(15,30,53,.14)`.
- Границы: 1px `--sd-border`; выбранное состояние — 1px `--sd-primary` плюс фон `--sd-primary-soft`.
- Кнопки: высота 36px (обычная) и 28px (компактная), радиус 8px, padding 0 16px, вес 500, без теней, hover — затемнение primary.

## 4. Правила применения

1. Синий — только для действий и активных состояний. Не для декора.
2. Статусы не кодируются одним цветом: цвет + текст + иконка/точка.
3. Рабочая область — `--sd-bg`, контент — белые карточки с бордером, без тяжёлых теней.
4. Таблицы плотные: строка 44px, шрифт 14px, цифры моноширинные.
5. Все интерактивные элементы имеют видимый фокус — 2px `--sd-focus` с отступом 2px.

## 5. Про ограничения исследования

По 4 сайтам (zendesk, freshworks, liveagent, zoho desk) получить CSS не удалось: блокировка TLS, пустой ответ или рендер только через JavaScript. Их значения не выдумывались и в частотный анализ не входят. По omnidesk и kayako сервер отдал 403 — взята только страница ошибки, без палитры. Итоговая система опирается на 12 сайтов, из них 10 с реальными цветами.
