Восемь модулей клиентской поддержки в одном окне

Рабочее пространство оператора

Восемь приложений на одном бэкенде: PHP 8.3 и Yii2 REST отдают данные, React 18 показывает интерфейс. Выберите раздел слева или карточку ниже.

8 модулей 8 PHP-сервисов 2 провайдера AI 0 ошибок линтера

Что под капотом

  • БэкендPHP 8.3 и Yii2 REST, восемь независимых сервисов
  • ФронтендReact 18, TypeScript, Vite, общий кит @sd/ui
  • ДанныеSQLite из коробки, PostgreSQL через DSN
  • AIофлайн-эвристика без ключа, OpenAI при SD_AI_API_KEY
  • ОкноElectron 45, процессы PHP и прокси поднимаются сами

Путь обращения

  1. Приходит в Inbox из Telegram, WhatsApp, почты, VK или чата.
  2. Размечается моделью: намерение, тема, приоритет.
  3. Встаёт в очередь Helpdesk, SLA следит за сроком ответа.
  4. Закрывается черновиком из Suggest, отзыв уходит в CSAT.
  5. Считается в Workload и Portal: нагрузка и маршрутизация.

Что проверено

  • Линтерсвои правила: один выход, функции в 1–2 строки, без while
  • Сборкаtsc --noEmit и vite build по всем восьми проектам
  • Связьhealth-точка у каждого модуля, статус виден в списке слева
  • Кадрыдевять скриншотов Playwright для README
